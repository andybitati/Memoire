# Politique Des Images Et Figures

Ce projet LaTeX n'a pas besoin d'images de reference provenant d'autres sites.

Toutes les images inserees dans le memoire sont locales et issues du travail:

- figures experimentales generees a partir des resultats Logminer;
- captures du dashboard Ariel Logminer;
- graphiques de latence, ressources, performances et robustesse;
- schema d'architecture logique du prototype.

## Pourquoi Ne Pas Ajouter D'Images Externes

Les images externes issues de sites web peuvent poser trois problemes:

1. droits d'auteur et autorisation de reproduction;
2. dependance a une source non controlee;
3. risque de decorer le memoire sans ajouter de preuve scientifique.

Pour un memoire technique, les figures les plus fortes sont celles produites
par le prototype lui-meme: architecture, resultats, tableaux, captures dashboard
et preuves experimentales.
