# Captures Dashboard

Date de verification: 2026-06-05

| Capture | Etat | Usage recommande |
| --- | --- | --- |
| `dashboard_vue_ensemble.png` | pret | Chapitre 4, vue generale du prototype et des indicateurs principaux |
| `dashboard_longue_vue.png` | pret | Chapitre 4 ou annexe, vue longue incluant les panneaux bas du dashboard |
| `dashboard_resultats_detail_incident.png` | pret | Chapitre 4/6, resultats, detail incident et decisions analyste |
| `dashboard_ressources_audit.png` | pret | Chapitre 5 ou annexe, ressources agents, services et audit |

Ces captures couvrent la vue generale, les resultats, le detail incident, les
ressources agents et l'audit. Elles suffisent pour documenter l'interface dans
la redaction du memoire et pour preparer une demonstration de soutenance.

Les fichiers `dashboard_capture_*.html` sont des wrappers locaux reproductibles
utilises pour regenerer les captures depuis le serveur dashboard local.
