ETAPES POUR ENTRAINER LE MODELE LOGMINER SUR GOOGLE COLAB
==========================================================

Note
----

Ce fichier etait initialement dedie a Kaggle. Le flux retenu pour le projet est
maintenant Google Colab + Google Drive, car les donnees volumineuses sont deja
stockees dans Drive et Colab peut monter Drive directement.

Kaggle reste possible si les donnees sont importees comme Dataset Kaggle, mais
Drive direct est plus simple avec Colab.


Objectif
--------

Entrainer le modele Isolation Forest sur Google Colab avec les datasets stockes
dans Google Drive, sauvegarder le modele au format `.joblib`, puis recuperer ce
modele pour l'utiliser localement dans Logminer avec l'option `--model-in`.

Le flux global est:

1. monter Google Drive dans Colab;
2. cloner le code du projet;
3. lire les donnees depuis `cloud_upload/logminer_cloud_data`;
4. construire un CSV d'entrainement cloud fusionne;
5. entrainer Isolation Forest;
6. sauvegarder le modele `.joblib` dans Drive;
7. reutiliser ce modele localement sur les logs Windows;
8. correler les anomalies en incidents.

Extraire `UNSWNB15.zip` dans `/content`:

```python
for zip_name in ["UNSWNB15.zip"]:
    zip_path = DRIVE_DATA / zip_name
    if zip_path.exists():
        target = EXTRACT_DIR / zip_path.stem
        target.mkdir(parents=True, exist_ok=True)
        with zipfile.ZipFile(zip_path, "r") as z:
            z.extractall(target)
        print("Extrait:", zip_path, "->", target)
    else:
        print("Absent:", zip_path)
```

for name in [

Construire le dataset reseau fusionne. Le script accepte maintenant:

- les CSV;
- les Parquet;
- plusieurs `--input-dir`;
- les sous-dossiers avec `--recursive`;
- `--sep auto` pour lire aussi bien `;` que `,`.
- `--dedupe name-size` pour ignorer les fichiers dupliques par nom et taille.

```python
!mkdir -p data/processed models

!python scripts/build_cloud_training_dataset.py \
  --input-dir "/content/logminer_network_data/extracted/UNSWNB15" \
  --input-dir "/content/logminer_network_data/network_sources" \
  --recursive \
  --sep auto \
  --dedupe name-size \
  --output data/processed/network_training_dataset.csv \
  --max-rows-per-file 50000
```

Remarque: si un autre ZIP contient les memes CSV que `UNSWNB15.zip`, le
parametre `--dedupe name-size` garde automatiquement une seule copie quand le
nom et la taille du fichier sont identiques. Pour une verification stricte,
utiliser `--dedupe hash`, mais cela lit tous les gros fichiers en entier et peut
prendre beaucoup plus de temps.

16. PROBLEMES FREQUENTS
-----------------------

Probleme: `credential propagation was unsuccessful`
Solution: relancer Colab, deconnecter et supprimer le runtime, puis remonter
Drive avec `force_remount=True`.

Probleme: `fatal: destination path 'TFE' already exists`
Solution: supprimer `/content/TFE` ou reutiliser le clone existant.

Probleme: `FileNotFoundError` sur les donnees Drive
Solution: verifier le chemin exact dans `MyDrive`, notamment les accents dans
`Memoire` / `Mémoire`.

Probleme: memoire insuffisante
Solution: reduire `--max-categorical-unique` a 100 ou diminuer
`--max-rows-per-file`.

Probleme: avertissement scikit-learn au chargement local
Solution: aligner la version scikit-learn locale avec celle de Colab, ou noter
cet ecart comme limite de reproductibilite.
