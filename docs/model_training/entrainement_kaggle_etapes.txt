ETAPES POUR ENTRAINER LE MODELE LOGMINER SUR GOOGLE COLAB
==========================================================

Note
----

Ce fichier etait initialement dedie a Kaggle. Le flux retenu pour le projet est
maintenant Google Colab + Google Drive, car les donnees volumineuses sont deja
stockees dans Drive et Colab peut monter Drive directement.

Kaggle reste possible si les donnees sont importees comme Dataset Kaggle, mais
Drive direct est plus simple avec Colab.


Objectif
--------

Entrainer le modele Isolation Forest sur Google Colab avec les datasets stockes
dans Google Drive, sauvegarder le modele au format `.joblib`, puis recuperer ce
modele pour l'utiliser localement dans Logminer avec l'option `--model-in`.

Le flux global est:

1. monter Google Drive dans Colab;
2. cloner le code du projet;
3. lire les donnees depuis `cloud_upload/logminer_cloud_data`;
4. construire un CSV d'entrainement cloud fusionne;
5. entrainer Isolation Forest;
6. sauvegarder le modele `.joblib` dans Drive;
7. reutiliser ce modele localement sur les logs Windows;
8. correler les anomalies en incidents.

5. CONSTRUIRE LE DATASET D'ENTRAINEMENT CLOUD
---------------------------------------------

```python
%cd /content/TFE

!mkdir -p data/processed models
!mkdir -p "/content/drive/MyDrive/Mémoire/cloud_upload/logminer_cloud_models"

!python scripts/build_cloud_training_dataset.py \
  --input-dir "/content/drive/MyDrive/Mémoire/cloud_upload/logminer_cloud_data/train" \
  --output data/processed/cloud_training_dataset.csv \
  --max-rows-per-file 50000
```

Remarques:

- `--max-rows-per-file 50000` evite qu'un seul gros dataset domine tout.
- Pour utiliser toutes les lignes, mettre `--max-rows-per-file 0`.
- Pour un dossier Drive nomme differemment, adapter les chemins exactement
  comme ils apparaissent dans Colab.


6. ENTRAINER ET SAUVEGARDER LE MODELE
-------------------------------------

```python
!python src/logminer/agents/detector.py \
  -i data/processed/cloud_training_dataset.csv \
  -o data/processed/cloud_training_anomalies.csv \
  --contamination 0.02 \
  --max-categorical-unique 200 \
  --model-out "/content/drive/MyDrive/Mémoire/cloud_upload/logminer_cloud_models/isolation_forest_colab.joblib"
```

Parametres importants:

- `--contamination 0.02`: le modele isole environ 2 % d'anomalies.
- `--max-categorical-unique 200`: conserve plus de categories one-hot.
- `--model-out`: sauvegarde directement le modele dans Google Drive.

8. VERIFIER LES RESULTATS DANS COLAB
------------------------------------

```python
from pathlib import Path
import pandas as pd

model_path = Path("/content/drive/MyDrive/Mémoire/cloud_upload/logminer_cloud_models/isolation_forest_colab.joblib")
anom_path = Path("/content/drive/MyDrive/Mémoire/cloud_upload/logminer_cloud_models/cloud_training_anomalies.csv")

print("Modele existe:", model_path.exists())
print("Taille modele:", model_path.stat().st_size if model_path.exists() else 0)

df = pd.read_csv(anom_path, sep=";")
print("Evenements:", len(df))
print("Anomalies:", int(df["is_anomaly"].sum()))
print("Taux:", float(df["is_anomaly"].mean()))
```

Un avertissement `DtypeWarning` peut apparaitre pendant la lecture du CSV. Il
n'est pas bloquant: il signale seulement que certaines colonnes melangent des
types differents, ce qui est attendu avec des journaux heterogenes.

13. FORMULATION POUR LE MEMOIRE
-------------------------------

Exemple de formulation:

> Le modele principal a ete entraine sur Google Colab afin de traiter un volume
> de donnees superieur aux capacites pratiques du poste local. Les donnees
> etaient stockees dans Google Drive et ont ete fusionnees dans un dataset de
> 287 862 evenements. Le modele Isolation Forest a ete entraine avec un taux de
> contamination fixe a 0,02, conduisant a l'identification de 5 754 anomalies
> candidates. L'artefact obtenu au format joblib contient le modele et le schema
> des features, ce qui permet sa reutilisation locale sans reentrainement. Lors
> de l'inference locale sur 61 313 evenements Windows, le modele a identifie 81
> anomalies candidates, ensuite regroupees en 71 incidents par l'agent de
> correlation.


14. PROBLEMES FREQUENTS
-----------------------

Probleme: `credential propagation was unsuccessful`
Solution: relancer Colab, deconnecter et supprimer le runtime, puis remonter
Drive avec `force_remount=True`.

Probleme: `fatal: destination path 'TFE' already exists`
Solution: supprimer `/content/TFE` ou reutiliser le clone existant.

Probleme: `FileNotFoundError` sur les donnees Drive
Solution: verifier le chemin exact dans `MyDrive`, notamment les accents dans
`Memoire` / `Mémoire`.

Probleme: memoire insuffisante
Solution: reduire `--max-categorical-unique` a 100 ou diminuer
`--max-rows-per-file`.

Probleme: avertissement scikit-learn au chargement local
Solution: aligner la version scikit-learn locale avec celle de Colab, ou noter
cet ecart comme limite de reproductibilite.
