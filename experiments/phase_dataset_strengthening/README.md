# Phase dataset strengthening

Cette arborescence contient uniquement les nouvelles preuves de renforcement des datasets.
Les campagnes historiques ne sont jamais écrasées. Les configurations sont gelées avant
exécution, les échecs sont conservés et le ledger est append-only.

Sous-dossiers produits par les runners : `raw/`, `processed/`, `aggregated/`, `figures/`,
`logs/`, `reports/` et `manifests/`.
